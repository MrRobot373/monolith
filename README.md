# MONOLITH

A self-hosted, **Perplexity-style AI portal for small organizations**. Staff open one site, log in,
and either **search for cited answers** or **pick a mode** (Law, Doctor/Health, Finance, Research,
Code, Cowork, Agent) to put an AI expert to work — all on infrastructure you control, routed through
one model gateway (cloud Claude/OpenAI/Gemini, or local models via Ollama).

Assembled from open-source projects; built on the **MIT-licensed core of
[OpenWork](https://github.com/different-ai/openwork)** + **Perplexica/Vane** + Anthropic's
open-source **[knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)**.

> **Status:** built and verified end-to-end on Docker.

---

## The three surfaces (one login)

| URL (local) | What it is |
|---|---|
| **http://localhost** | **The Hub** — Perplexity-style launcher: a search bar + mode tiles |
| **http://work.localhost** | **OpenWork** workspace (the agentic "do the work" engine) |
| **http://localhost:3001** | **Perplexica/Vane** — cited AI web search |

The Hub's **search bar** → Vane (sourced answers). The **mode tiles** → OpenWork, opening a session
pre-set to that domain's expert agent:

| Mode | Opens |
|---|---|
| Research | Vane search |
| Law | OpenWork · `legal` agent (review-contract, triage-nda, compliance…) |
| Doctor / Health | OpenWork · `health` agent |
| Finance | OpenWork · `finance` agent (financial-statements, reconciliation…) |
| Deep Research | OpenWork · `research` agent (web-reach + report) |
| Code | OpenWork · `code` agent (+ `occ` / opencode) |
| Cowork / Agent | OpenWork · default agent |

Modes are declared in [hub/modes.json](hub/modes.json) — edit that to add/rename tiles. Domain agents
live in [workspace-image/seed/.opencode/agent/](workspace-image/seed/.opencode/agent/).

## Quick start

```bash
cp .env.example .env          # or: scripts/new-instance.sh (generates secrets)
# add a provider key for good answers: ANTHROPIC_API_KEY= (best) or GEMINI_API_KEY=
docker compose up -d --build
docker compose exec ollama ollama pull qwen2.5:0.5b      # tiny test model; pull a bigger one for real use
```

- Open **http://localhost**, log in (`admin` / `Monolith-74967bd1` — change it below).
- Pick a mode or search. In OpenWork, choose a model: **Claude / GPT / Gemini (cloud)** or **Qwen (local)**.

**Change the login:** `scripts/set-admin-password.sh admin '<new-pass>' && docker compose restart caddy`

**Get good answers:** the bundled local model is tiny. Put **one** key in `.env`
(`ANTHROPIC_API_KEY=` recommended), then `docker compose up -d --force-recreate litellm`.

## Multi-user (isolated workspaces)

```bash
scripts/add-user.sh alice 20 alicepass     # -> http://alice.localhost, own container+data+$20/mo budget
```

Each user gets their own container, volumes, login, and gateway budget key (isolation verified).

## Operations

| Script | Purpose |
|---|---|
| `scripts/new-instance.sh` | Fresh client instance with generated secrets |
| `scripts/add-user.sh <user> [budget] [pass]` | Isolated per-user workspace |
| `scripts/backup.sh` / `restore.sh` | Snapshot / restore all data (volumes) |
| `scripts/set-admin-password.sh <user> <pass>` | Change the login |

## Layout

```
docker-compose.yml     # the whole stack
hub/                   # the Hub launcher (index.html + modes.json), served by Caddy
webui/                 # builds & serves the OpenWork React UI (branded, ?agent= deep-link)
workspace-image/       # OpenWork workspace container: engine + agent tools + domain agents/skills
  seed/.opencode/agent # domain agent personas (legal/finance/health/research/code)
litellm/config.yaml    # model aliases (cloud + local) + round-robin router
caddy/Caddyfile        # login, routing (hub / work / search), TLS, headers
caddy/users/           # per-user routes (generated by add-user.sh)
openwork/              # upstream reference clone (webui builds the UI from here)
```

## Notes / production follow-ups
- **One password, per-host prompt:** login is HTTP Basic, so browsers prompt once per host
  (hub / work / search) per session. True no-reprompt **SSO = an Authelia upgrade** (documented next step).
- **Model quality** depends on a real key in `.env` (local Qwen is weak).
- **Domain modes:** Law/Finance reuse real plugin skills; Health/Research/Code use tuned personas.
- Deep visual rebrand of the OpenWork UI (beyond the product name) is a later, careful task.
