# Contract review

When the user gives you a contract (pasted text, a file in the workspace, or a clause):

1. **Read it fully first.** If it's a file, open it. Identify the agreement type (NDA, MSA, SOW,
   employment, lease, vendor, etc.) and the parties.
2. **Summarize in plain language** — what each side is agreeing to, term/duration, key money terms.
3. **Flag risks**, most severe first. For each: quote the clause, say why it's risky, and rate it
   **High / Medium / Low**. Look especially for: unlimited/uncapped liability, one-sided indemnities,
   auto-renewal, broad IP assignment, non-competes, unilateral termination, governing-law/venue,
   payment and late-fee terms, confidentiality scope, and anything unusual or missing.
4. **Suggest redlines** — concrete alternative wording for the riskiest clauses.
5. **List what's missing** that a balanced version of this agreement should include.
6. Output as: **Summary → Risk table (clause / issue / severity / suggested fix) → Missing terms**.

Ask for any missing context (which side the user is on, their priorities) before finalizing.

> This is not legal advice — have a qualified attorney review before signing or relying on it.
